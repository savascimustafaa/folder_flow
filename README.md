📁 Folder-Flow (Dosya Düzenleyici)

Klasörlerinizi karmaşadan kurtarın! Folder-Flow, dağınık durumdaki klasörlerinizi belirlediğiniz kriterlere göre tarayan, dosyaları türlerine ve oluşturulma tarihlerine göre otomatik olarak organize eden kullanıcı dostu bir masaüstü uygulamasıdır.

🚀 Özellikler

Akıllı Sınıflandırma: Dosyaları türlerine (belgeler, resimler, videolar vb.) ve tarihlerine göre otomatik olarak yeni klasörlere taşır.

↩️ Geri Al (Undo): Yanlışlıkla yapılan düzenleme işlemlerini tek bir tıkla eski haline getirin.

🔍 Alt Klasör Taraması: İsteğe bağlı olarak hedef klasörün altındaki tüm klasörleri de derinlemesine tarar.

⚙️ Özelleştirilebilir Ayarlar: Hangi dosya türünün nereye gideceğini "Ayarlar" menüsünden kendiniz belirleyin.

📝 Detaylı İşlem Geçmişi: Uygulama içindeki log ekranı sayesinde hangi dosyanın nereye taşındığını veya olası hataları anlık olarak takip edin.

🔒 Güvenli: Dosyalarınıza zarar vermez, taşıma işlemlerini güvenli bir şekilde gerçekleştirir.

🛠️ Kurulum

Projeyi bilgisayarınızda çalıştırmak için işletim sisteminize uygun aşağıdaki adımları izleyebilirsiniz.

🪟 Windows Kullanıcıları İçin

Projeyi klonlayın ve klasöre gidin:

git clone https://github.com/KULLANICI_ADINIZ/folder-flow.git
cd folder-flow


Sanal ortam oluşturun ve aktif edin:

python -m venv venv
venv\Scripts\activate


Gerekli kütüphaneleri yükleyin:

pip install -r requirements.txt


Uygulamayı çalıştırın:

python main.py


🐧 Linux Kullanıcıları İçin

Projeyi klonlayın ve klasöre gidin:

git clone https://github.com/KULLANICI_ADINIZ/folder-flow.git
cd folder-flow


Sanal ortam oluşturun ve aktif edin:

python3 -m venv venv
source venv/bin/activate


Gerekli kütüphaneleri yükleyin:

pip install -r requirements.txt


Uygulamayı çalıştırın:

python3 main.py


💻 Kullanım

Dizin Seçin: "Klasör Seç" butonuna basarak düzenlemek istediğiniz hedef klasörü seçin.

Alt Klasörleri Dahil Edin: Eğer seçtiğiniz klasörün altındaki klasörlerin de taranmasını istiyorsanız "Alt Klasörleri Tara" seçeneğini işaretleyin.

Düzenleyin: "Düzenle" butonuna tıklayarak işlemi başlatın. İşlem durumu alt kısımdaki log ekranından takip edilebilir.

Geri Alın: Yapılan işlemi geri almak isterseniz kırmızı "Geri Al" butonunu kullanabilirsiniz.
